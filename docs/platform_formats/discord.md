# Discord Platform Format Rules

- **Max characters**: 2,000 per message. Split long items into threads.
- **Hashtags**: Not required; use channel mentions instead (#announcements).
- **Links**: Allowed; keep to 3 or fewer per message.
- **Mentions**: Prefer role mentions; cap at 2 to reduce noise.
- **Tickers**: Plain text or $TICKER; avoid flooding messages.
- **Markdown**: Bullets for value items, bold CTA.
- **CTA block**: Discord is the destination; still include Website + Free Tool + Membership links for clarity.
