# X (Twitter) Platform Format Rules

- **Max characters**: 280 per post; threads auto-split every 240 chars for buffer.
- **Hashtags**: 0–3; prefer tickers instead.
- **Links**: 1 per tweet max; shorten and track.
- **Mentions**: Keep under 3 to reduce spam risk.
- **Tickers**: Convert to $TICKER; limit to 3 per tweet.
- **Threads**: 3–6 tweets ideal; include CTA in final tweet.
- **CTA block**: Profile link to Discord + Website; include Free Tool + Membership in closing tweet.
