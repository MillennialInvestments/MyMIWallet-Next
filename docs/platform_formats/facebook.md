# Facebook Platform Format Rules

- **Max characters**: Aim for <2,200; prioritize first 140 chars for hook.
- **Hashtags**: 2–5 targeted hashtags; place at end.
- **Links**: 1–2 per post; prefer shortened URLs with UTM.
- **Mentions**: Pages/Groups allowed; keep minimal.
- **Tickers**: Plain text or $TICKER acceptable.
- **Content mix**: Reels, static posts, polls; keep thumbnails branded.
- **CTA block**: Discord invite + Website + Free Tool + Membership.
