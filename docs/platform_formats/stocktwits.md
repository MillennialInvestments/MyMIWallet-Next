# StockTwits Platform Format Rules

- **Max characters**: Target <280 even though limit ~1,000.
- **Hashtags**: Minimal; rely on $TICKER tagging.
- **Links**: 1 allowed; keep short and relevant.
- **Mentions**: Up to 3; stay contextual.
- **Tickers**: REQUIRED as $TICKER; ensure every ticker is prefixed.
- **Content mix**: Idea posts, quick questions, watchlist updates.
- **CTA block**: Bio links to Discord + Website + Free Tool + Membership; keep in post only when space allows.
