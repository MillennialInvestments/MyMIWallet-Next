# YouTube Platform Format Rules

- **Max characters**: Title 100; prioritize hook + ticker. Description flexible but front-load CTA in first 200 chars.
- **Hashtags**: 3–8 recommended; place at end of description.
- **Links**: Allowed in description and pinned comment; limit to 3 unique domains to avoid spam flags.
- **Mentions**: @Channel supported in title/description.
- **Tickers**: Plain (AAPL) or $TICKER in description.
- **Shorts vs Long**: Shorts <60s vertical; long-form structured with chapters.
- **CTA block**: Include Discord + Website + Free Tool + Membership link; mirror in pinned comment.
