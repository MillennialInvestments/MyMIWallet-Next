# Twitch Platform Format Rules

- **Titles**: Concise with tickers/subjects; avoid clickbait.
- **Tags**: 5–10 relevant tags for discoverability.
- **Links**: In panels and chat commands; keep short and validated.
- **Mentions**: Use @user sparingly in chat; avoid clutter.
- **Tickers**: Plain text tickers in title/description; overlay graphics acceptable.
- **Clips**: 30–90s highlights; include CTA lower-third when exported.
- **CTA block**: Panels for Discord + Website + Free Tool + Membership; chat command `!discord` mirrored.
