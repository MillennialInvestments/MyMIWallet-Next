# TradingView Indicator Documentation Hub

This folder houses publish-ready documentation for TradingView indicators associated with the MyMI Wallet ecosystem. Each indicator page follows a consistent structure so future additions stay easy to navigate, reuse, and publish.

## Standard Document Structure

Use the template in [`_template.md`](./_template.md) when adding new indicator docs. The recommended sections are:

1. Overview
2. Components or logic summary
3. Inputs (with defaults and performance considerations)
4. How to use / workflows
5. Visual outputs (screenshots or diagram notes)
6. Alerts
7. Limitations
8. Publishing notes (category, tags, description guidance)
9. Changelog (optional)
