# Controller Refactor Plan

| Controller | Issue | Proposed Fix | Files Affected | Risk |
|---|---|---|---|---|
| `App\Modules\APIs\Controllers\AIOpsAPIController` + `AiOpsAPIController` | Overlapping AI Ops authorization/toggle responsibilities | Use shared `InternalEndpointGuardService`; progressively move AI Ops business logic to dedicated services and keep one canonical controller | `app/Modules/APIs/Controllers/AIOpsAPIController.php`, `app/Modules/APIs/Controllers/AiOpsAPIController.php`, `app/Services/InternalEndpointGuardService.php` | LOW |
| `App\Modules\User\Controllers\InvestmentsController` + `App\Modules\APIs\Controllers\InvestmentsAPIController` | Similar investment retrieval endpoints in user and API layers | Continue extraction into `InvestmentService`; map both controllers to service methods and trim controller logic | `app/Modules/User/Controllers/InvestmentsController.php`, `app/Modules/APIs/Controllers/InvestmentsAPIController.php`, `app/Services/InvestmentService.php` | MEDIUM |
| `Support` controller family (`Support`, `SupportController`, `SupportAPIController`) | Repeated request handling and support data access | Introduce `SupportService` for validation + persistence and use thin controllers for web/API | `app/Modules/Support/Controllers/*.php`, `app/Modules/APIs/Controllers/SupportAPIController.php`, `app/Services/SupportService.php` | MEDIUM |
| Duplicate class names (`HealthController`, `UserController`, `SearchController`, `PrivacyController`, etc.) | Potential developer confusion and accidental wrong imports | Keep namespaces explicit; optionally rename with context suffix where practical | Multiple controller files | LOW |
| Base inheritance migration (Phase 1) | Controllers do not yet share API/Admin/User base behavior consistently | Introduce `BaseAPIController`, `BaseUserController`, `BaseAdminController` and migrate a safe initial set of controllers | `app/Controllers/BaseAPIController.php`, `app/Controllers/BaseUserController.php`, `app/Controllers/BaseAdminController.php`, selected module controllers | LOW |
| Alerts controller group (`AlertsController`, `AlertsAPIController`, `AlertsAdminController`) | Duplicated commentary/social alert flows and direct model/library wiring in controllers | Route shared alert operations through `AlertService`; keep controllers thin and module-specific | `app/Services/AlertService.php`, `app/Modules/APIs/Controllers/AlertsAPIController.php`, `app/Modules/Management/Controllers/AlertsAdminController.php`, `app/Modules/User/Controllers/AlertsController.php` | MEDIUM |
| `App\Modules\Support\Controllers\Support` (legacy duplicate) | Unused by current `Routes.php`; overlaps with `SupportController` responsibilities | Move to `app/Deprecated/Controllers/LegacySupportController.php` for safe archival before eventual removal | `app/Modules/Support/Controllers/Support.php`, `app/Deprecated/Controllers/LegacySupportController.php` | LOW |
| `App\Modules\User\Controllers\SupportController` (legacy duplicate) | No active route references in current `Routes.php`; overlaps with module support controllers | Move to `app/Deprecated/Controllers/LegacyUserSupportController.php` and keep active support routing in `App\Modules\Support\Controllers` | `app/Modules/User/Controllers/SupportController.php`, `app/Deprecated/Controllers/LegacyUserSupportController.php` | LOW |
| `App\Controllers\HowItWorksController` (legacy duplicate) | Root-level duplicate conflicts with module `HowItWorksController`; not targeted by active route group | Move to `app/Deprecated/Controllers/LegacyHowItWorksController.php` and keep module public routes canonical | `app/Controllers/HowItWorksController.php`, `app/Deprecated/Controllers/LegacyHowItWorksController.php`, `app/Config/Routes.php` | LOW |
| `App\Modules\Template\Controllers\TemplateController` (legacy duplicate) | No active route references in current `Routes.php`; placeholder/module stub controller | Move to `app/Deprecated/Controllers/LegacyTemplateController.php` | `app/Modules/Template/Controllers/TemplateController.php`, `app/Deprecated/Controllers/LegacyTemplateController.php` | LOW |
| Module-wide base inheritance normalization (API/User/Management) | Mixed controller parents caused architecture drift and duplicated bootstrap behavior | Standardize all module controllers to `BaseAPIController`, `BaseUserController`, `BaseAdminController` (allowing intermediate base classes that inherit from these) | `app/Modules/APIs/Controllers/**/*.php`, `app/Modules/User/Controllers/**/*.php`, `app/Modules/Management/Controllers/**/*.php`, `docs/refactor/controller_migration_map.md` | MEDIUM |
