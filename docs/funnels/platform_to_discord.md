# Platform → Discord Routing

- Add Discord link to every profile bio and pinned post.
- Include Discord in CTA blocks for YouTube descriptions, TikTok comment pins, Twitch panels, Facebook pinned posts, LinkedIn custom button, X pinned tweet, and StockTwits bio.
- Use UTM parameters for each platform to measure conversion.
- Monitor discord invite joins per platform in Management → Communities Hub.
- Require manual approval before scheduling external webhooks to avoid spam.
