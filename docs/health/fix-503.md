# `php spark fix:503`

## Purpose
Runs a full 503 auto-triage sequence for MyMI Wallet (CI4) to diagnose PHP-FPM, disk, socket, and bootstrap issues, then applies **safe** auto-fixes only when allowed.

## When to use
- The site returns **503 Service Unavailable**.
- You need a **forensic log** of all diagnostics and decisions.

## What it does (step-by-step)
1. **Creates a log file** in `writable/triage/503/503-YYYY-MM-DD-HHMMSS.log`.
2. **Web reachability**: `curl -I https://www.mymiwallet.com` (logs status + headers).
3. **Disk + inode checks**: `df -h` and `df -i`.
   - If any filesystem is **>90%**, the command **logs a warning** and **blocks auto-fixes**.
4. **PHP-FPM status**: `systemctl status php8.2-fpm` + `ps aux | grep php-fpm`.
5. **Socket mismatch check**:
   - `grep fastcgi_pass /etc/nginx/sites-enabled/*`
   - `ls /run/php/`
   - If nginx points to a missing socket, it **queues** a php-fpm restart for the final phase.
6. **CI4 bootstrap health**: `php spark app:config`.
   - If this fails, the command **clears writable cache paths** (only when auto-fix is allowed):
     - `writable/cache/*`
     - `writable/debugbar/*`
     - `writable/session/*`
7. **Autoload refresh**: `composer dump-autoload -o` (warn-only on failure).
8. **Writable permissions check**: `ls -ld writable`.
   - If permissions are not `drwxrwxr-x`, it runs `chmod -R 775 writable` (only when auto-fix is allowed).
9. **PHP-FPM error log tail**: `tail -n 200 /var/log/php8.2-fpm.log` (if present).
10. **Final safe restart** (last resort):
   - If a socket mismatch was detected and auto-fix is allowed, runs:
     - `systemctl restart php8.2-fpm`

## Output
Prints a final report:

```
==============================
 MyMI Wallet – 503 TRIAGE
==============================

Root Cause:
✔ PHP-FPM socket mismatch

Actions Taken:
✔ Cleared CI4 cache
✔ Restarted php8.2-fpm

Actions NOT Taken:
✖ Nginx restart (manual required)

Risk Level:
LOW

Recommended Follow-Up:
- Review php-fpm pool config
- Add watchdog to detect worker death
```

## Safe-guarding behavior
- **Never restarts nginx automatically**.
- **Blocks all auto-fixes** if disk/inode usage exceeds 90%.
- Supports `--dry-run` to log diagnostics without changes.

- `php spark health:services`
- `php spark health:cache`
