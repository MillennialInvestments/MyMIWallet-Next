# Gap Tracker Auto-Fill and Next-Work Engine

This folder contains the automated enrichment flow for `docs/gap_tracker/gap_tracker.csv` plus daily/adhoc reports that surface the next deterministic work items.

## Files
- `gap_tracker.csv`: canonical tracker (copied from the historical gap-audit sheet).
- `reports/`: dated markdown reports generated by the sync command.
- `app/Commands/GapTrackerSync.php`: spark command that enriches the CSV and produces the reports.

## Column semantics
- **Status**: `Gap`, `In Progress`, or `Done` (auto-default is `Gap`).
- **Priority**: `P0` (critical exploit/auth), `P1` (security/auth/payments/predictions/devops/alerts), `P2` (general/product/content), `P3` (long tail).
- **Estimated Effort**: `S` (small route/fix), `M` (most work), `L` (larger dashboards/migrations/integrations).
- **Doc Source**: relative doc path with line markers (e.g., `docs/predictions/README.md:L20`).
- **Code Evidence**: relative code path with line markers (e.g., `app/Config/Routes.php:L412`). Use `NaN` when no evidence found.
- **Dependencies**: `None` or blocking files/areas (e.g., `app/Config/Routes.php`, `app/Database/Migrations`).
- **Owner**: defaults to `Teddy` (use `MyMIAutomation` for purely automated chores).
- **Target Version**: defaults to `vNext`.
- **Notes**: 2–5 bullets with hints, file touch list, and acceptance criteria.

## Selection algorithm (Next Work)
1. Filter rows with Status in `Gap` or `In Progress`.
2. Exclude rows whose Dependencies are set (anything other than `None`).
3. Sort by Priority (P0 → P1 → P2 → P3) then Effort (S → M → L).
4. Emit the top 5 as the recommended immediate queue; top 10 for backlog visibility.

## Command usage
Run the enrichment and generate a report:

```bash
php spark gap:sync
```

Options:
- `--limit=25` — maximum rows to process this run (defaults to 25).
- `--priority=P1` — only process rows matching this priority (helps keep the bill low).
- `--dry-run` — preview changes and report without writing the CSV.

Reports are written to `docs/gap_tracker/reports/gap_sync_YYYY-MM-DD.md` and include fill counts, missing doc/code evidence, and the "Next 5" queue with PR scaffolding.
