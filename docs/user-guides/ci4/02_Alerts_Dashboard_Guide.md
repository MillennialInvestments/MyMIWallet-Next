# Alerts Dashboard Guide

Use the Alerts dashboard to manage and review trading signals that also appear in Discord.

## Filter and search
- Filter by date range, symbol, or category to find the alerts you need.
- Sort by newest to see what just went to Discord.
- Apply watchlist filters to focus on symbols you care about.

## Create alerts manually
1. Choose the symbol, entry, stop loss, and target levels.
2. Select distribution channels (including Discord) before saving.
3. Save to queue the alert for delivery.

## Understand the alert lifecycle
- **Open:** Initial post with entry, stop, and targets.
- **Updated:** Targets/stops adjusted; sends an update to Discord.
- **Closed:** Final state with outcome notes.

## View alert history
- Open an alert to see past updates, timestamps, and whether Discord notifications were sent.
- Use history to reconcile what you saw in Discord with on-site data.

## TradingView chart overrides
- Replace or refresh chart snapshots if the automated capture missed a key level.
- Upload or re-run the chart generation, then republish to Discord if needed.

## How Discord notifications relate
- Alerts marked for Discord dispatch flow through the queue with pacing and quiet hours.
- If you edit an alert, an update post can be sent to the same channel.
- Premium channels receive richer details based on membership tiers.
