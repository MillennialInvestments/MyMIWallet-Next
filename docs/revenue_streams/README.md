# Revenue Streams Scanner

This directory is generated by `php spark revenue:scan`.

- revenue_streams_full.md
- revenue_streams_by_module.md
- revenue_streams_by_user_type.md
- revenue_streams_by_pricing_tier.md

The command scans app modules, libraries, services, and docs for monetizable features (membership, premium, alerts, automation, etc.) and groups them by module, user type, and pricing tier.
