# MyMI Wallet log cleanup + UX fix — 2026-01-01

## What changed

- Normalized all route method strings to uppercase and added explicit routes for `/health`, `/status`, `/Support/FAQ`, and legacy content slugs (Subscribe daily news + Blog/Investing) to prevent CI4 route deprecation spam and 404 noise.
- Hardened login redirect handling to ignore empty, logout, or off-site destinations and always fall back to the dashboard after clearing the session flag.
- Reduced guest-request log spam by skipping user hydration when no authenticated ID is present and by removing repetitive debug logs from `UserModel`/`MyMIUser`.
- Fixed PHP 8.2 `nl2br(null)` deprecation in the 404 view and declared the missing `$userAccount` property on `HowItWorksController`.
- Seeded SEO/meta rows for `how-it-works/*` slugs (overview, marketing, investments, earnings, account-settings) to avoid MetaService fallback logging.

## Follow-up

- Run the new `HowItWorksMetaSeeder` if you want the SEO records persisted in `bf_marketing_page_seo`:
  ```bash
  php spark db:seed HowItWorksMetaSeeder
  ```
- Restart FPM/Nginx after deploying to pick up the new `/health` + `/status` endpoints in upstream checks if they are cached.
