# Fix503 (DreamHost-aware)

## Overview
`fix:503` diagnoses 503 errors on DreamHost by checking disk pressure, PHP backends, nginx socket alignment, CI4 CLI health, and writable permissions. It avoids `systemctl` and provides panel-friendly action hints.

## Run
```bash
php spark fix:503
```

### Dry run
```bash
php spark fix:503 --dry-run
```

## What it checks
- HTTP reachability for www.mymiwallet.com.
- Disk and inode pressure.
- DreamHost PHP backend (php82.cgi/php-cgi/supervisord processes + socket discovery).
- nginx `fastcgi_pass` alignment with detected DreamHost sockets under `~/nginx`.
- CI4 CLI bootstrap (`php spark app:config`).
- `writable/` permissions and cache directories.
- php-fpm log tail (if present).
- EnvDoctor snapshot summary + output paths.

## DreamHost-specific behavior
- No `systemctl` usage (DreamHost uses user-space daemons).
- PHP sockets checked in `~/.php.sock`, `~/.php82.sock`, and `~/.local/phpcgi/run/*.sock`.
- nginx configs are read from the home prefix in `Config\Ops::$homeNginxPrefix`.
- If `fastcgi_pass` points to the wrong socket, a suggested snippet is generated at:
  - `writable/triage/503/nginx-fastcgi-fix-YYYY-mm-dd-His.conf`

## Panel action hints
When a backend mismatch or missing process is detected, Fix503 will recommend:
- **DreamHost panel:** Toggle PHP version or restart the web server.
- **Home nginx:** `nginx -p ~/nginx -c conf/nginx.conf -t && nginx -p ~/nginx -c conf/nginx.conf -s reload`

## Output
- Fix503 writes a log in `writable/triage/503/503-YYYY-mm-dd-His.log`.
- EnvDoctor artifacts are stored in `writable/triage/envdoctor/` and the paths are included in the Fix503 report.
