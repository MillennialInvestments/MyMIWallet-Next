# Operations Environment Variables

- `INTERNAL_API_TOKEN`: Shared secret for internal orchestration API calls.
- `N8N_BASE_URL`: n8n instance URL for links and callbacks.
- `MYMI_BASE_URL`: MyMI Wallet base URL used by n8n HTTP nodes.
- `DISCORD_WEBHOOK_URL`: Discord webhook destination for alerts.
- `SMTP_HOST`: SMTP server host.
- `SMTP_PORT`: SMTP server port.
- `SMTP_USER`: SMTP auth username.
- `SMTP_PASS`: SMTP auth password.
- `SMTP_FROM`: sender email address.
- `SMTP_TO`: recipient email address(es).
