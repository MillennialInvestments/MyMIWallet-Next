# 2025-12-25 Log Summary Fixes

## Root causes
- **Response type mismatch:** `App/Modules/Blog/Controllers/HowItWorksController::show` returned a string instead of a `ResponseInterface`, triggering a fatal type error. 【app/Modules/Blog/Controllers/HowItWorksController.php】
- **Missing dynamic routes:** `/Knowledgebase/Getting-Started` and several `/How-It-Works/*` slugs were not explicitly routed, producing 404 misses. 【app/Config/Routes.php】
- **Absent config usage:** `MyMINews` expected a missing config; now it reuses the existing `APISettings` (env-aware) for NewsAPI keys. 【app/Libraries/MyMINews.php】【app/Config/APISettings.php】
- **Solana rate-limit noise:** RPC 429 responses were logged repeatedly and circuits stayed half-effective. 【app/Services/SolanaService.php】
- **Solana data type safety:** `MyMISolana::getUserSolana` and `BaseController::commonData` assumed array shapes, leading to “offset on string” when failures returned unexpected data. 【app/Libraries/MyMISolana.php】【app/Controllers/BaseController.php】
- **Memory pressure:** `commonData()` eagerly loaded heavy wallet/budget/Solana data on all pages and lacked list caps/telemetry to diagnose spikes. 【app/Controllers/BaseController.php】

## Changes made
- Wrapped How-It-Works rendering in response helpers and added slug normalization + view mappings for the missing pages to return a proper `ResponseInterface`. 【app/Modules/Blog/Controllers/HowItWorksController.php】
- Added catch-all Knowledgebase route + slug resolver and made routes for lowercase `how-it-works` group point to the correct namespace. 【app/Config/Routes.php】【app/Modules/User/Controllers/KnowledgebaseController.php】
- Reused `APISettings` (with env override support) for NewsAPI settings to satisfy existing library usage. 【app/Libraries/MyMINews.php】【app/Config/APISettings.php】
- Hardened Solana RPC client with normalized responses, immediate circuit opens on 429 (respecting `Retry-After`), jittered backoff, endpoint rotation defaults, and rate-limit log throttling. 【app/Services/SolanaService.php】
- Ensured `MyMISolana::getUserSolana` always returns a structured array (with safe defaults) and normalized market data parsing; BaseController now guards Solana payload shapes before indexing. 【app/Libraries/MyMISolana.php】【app/Controllers/BaseController.php】
- Added telemetry gating (`app.debugTelemetry`), capped list sizes in `commonData()`, skipped heavy loaders on public pages, and recorded memory snapshots at start/end (and early-return) to mitigate and diagnose memory exhaustion. 【app/Controllers/BaseController.php】
- Updated smoke test script to cover the previously failing routes and policy pages. 【scripts/smoke_routes.sh】

## How to test
1. `php spark routes | grep -E "How-It-Works|Knowledgebase"` – confirm new routes are registered.
2. `bash scripts/smoke_routes.sh https://www.mymiwallet.com` – ensure key public URLs return 200/301/302.
3. Hit `/How-It-Works/Registering-An-Account` and `/Knowledgebase/Getting-Started` in a browser; verify content renders without 404s.
4. Exercise a Solana RPC call (e.g., a dashboard action) and observe logs: first 429 should open the circuit (NOTICE), repeats should not emit ERROR spam.
5. With `app.debugTelemetry=true`, inspect logs for `telemetry:commonData:*` entries showing memory usage before/after heavy sections.
