# AIOps Workflow Outputs

This folder holds the outputs generated by n8n workflows for MyMI Wallet. To keep access safe and predictable, n8n should only read and write inside `~/mymiwallet/site/current/` and persist workflow outputs under `~/mymiwallet/site/current/docs/`.

## Directory layout
- `docs/_aiops/inventory/` – inventory reports such as `docs_inventory.md` and per-subdirectory inventories.
- `docs/_aiops/reports/` – routine reports (module maps, static analysis digests, security audit summaries, PR readiness checks, etc.).
- `docs/_aiops/diffs/` – suggested patch proposals that Codex can later apply to the repository.
- `docs/_aiops/next-steps/` – generated next-step plans for each docs subdirectory or security follow-ups.

Use these folders as the canonical pipeline for "n8n generates → Codex applies" automation. Each workflow should write its artifacts into the appropriate subfolder to keep outputs organized and reviewable.
