## Summary of Changes
- **Alert Creation Certification (`AlertService::createTradeAlert`):**
  - Added strict input validation for symbol formatting and session user ownership (`$sessionUserId > 0`).
  - Implemented auto-computation of target prices (+3% profit target) and trailing locked profit stops if not explicitly provided.
  - Implemented duplicate active alert detection preventing duplicate open alerts for the same symbol.
  - Hardened `AlertsAdminController::addTradeAlert()` to resolve user identity strictly from the active session (`$this->cuID`), and fixed undefined property `$this->alertModel` -> `$this->alertsModel`.
- **Alert Evaluation Certification (`AlertService::evaluateAlert`, `evaluateActiveAlerts`):**
  - Integrated market quote resolution using `MarketDataFreshnessService::resolveSafePrice()` with tiered fallbacks.
  - Automatically evaluates active trade alerts against current market price: triggers `Target Hit` when current price $\ge$ target price, `Stop Hit` when current price $\le$ stop loss, or retains `Opened` when in range.
  - Bounded active alert batch evaluations with `limit(1)` and `limit($limit)`.
  - Persists status transitions and writes atomic snapshot entries to `bf_investment_alert_history`.
- **Alert Delivery Certification (`AlertService::deliverAlert`):**
  - Implemented multi-channel delivery support for Discord and Email.
  - Guarded against accidental broadcast in test and non-production environments with dry-run support.
  - Sets `send_alert = 1`, `alert_sent = 1`, and `notification_sent = 1` upon dispatch, and records history event.
- **Alert History Certification (`AlertService::getUserAlertHistory`, `getAlertHistoryBySymbol`):**
  - Hardened user-scoped history queries to prevent IDOR disclosure across accounts.
  - Added `user_id` support and defensive column checks in `AlertsModel::recordAlertHistory()` and `AlertsModel::getFilteredUserAlerts()`.
  - Corrected `AlertsController::viewAlert()` invalid redirect from non-existent `/Users/Alerts` to `/Alerts`.
- **Route Handler Gap Ratchet Reduction (GTM-024):**
  - Implemented 4 missing route handlers in `AlertsAPIController`: `fetchAutoGeneratedAnalysis`, `generateNow`, `research`, and `updateStatus`.
  - Shrunk `tests/baseline/route-handler-gaps.txt` baseline ratchet from 162 to 158 lines.
  - Registered user alert view and history routes (`Alerts/View/(:num)`, `Alerts/viewAlert/(:num)`, `Alerts/filterAlerts`, `Alerts/getUserAlerts`, `Alerts/userAlerts`) in `app/Config/Routes.php`.
- **Spark CLI Command (`app/Commands/Alerts/Evaluate.php`):**
  - Created `php spark alerts:evaluate` with `--json` and `--limit` support.
  - Registered in `app/Config/Console.php` and `app/Config/Commands.php`.
- **Unit & Certification Suite (`tests/unit/Alerts/AlertPipelineTest.php`):**
  - 14 tests (61 assertions) covering creation, target calculation, duplicate prevention, evaluation, target/stop transitions, delivery, history isolation, controller endpoints, and Spark CLI command.
